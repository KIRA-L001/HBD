# 🎂 Happy Birthday (HBD)

A Happy Birthday animation built with HTML5, CSS3, and jQuery — animated balloons, lights, cake, and music.

## Run Locally

### With Python

```bash
python -m http.server 8081
```

Visit http://localhost:8081 in your browser.

### With Node.js

```bash
npm install
npm run server-node
```

Visit http://localhost:8081 in your browser.

## Tech Stack

- HTML5 / CSS3 (LESS)
- jQuery animations
- Audio playback (`hbd.mp3`)
